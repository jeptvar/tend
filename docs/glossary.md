# Words we use

So that the admin, the messages and the guide say the same thing for the same thing. `messages.test.ts` fails on words from the last column.

| We say | For | We don't say |
|---|---|---|
| **Page** | Something that stays where it is, such as About | Entry |
| **Post** | Something with a date, on the blog | Entry, article |
| **Draft**, **Published** | Whether it's on the site | Status, state |
| **Changes saved, not on your site yet** | Published, with newer edits | Dirty, pending |
| **Publish**, **Publish changes** | Putting it on the site | Deploy, push |
| **On your site** | Visitors can see it | Live, unless anyone can reach the site |
| **Homepage** | The page at the site's own address | Front page, index |
| **Site menu** | The links at the top and bottom | Navigation, nav |
| **Design** | Colours, fonts, logo | Theme options, appearance |
| **Theme** | The files that draw the site | Template, skin |
| **Section** | A part of a page with its own background | Block, component |
| **Big intro** | The big words at the top of a page | Hero, banner |
| **Address** | Where something is: a page's, or the site's | URL, slug, permalink, path |
| **Summary** | A sentence or two about it | Excerpt, meta description |
| **Describe this image** | What's in a picture, for people who can't see it | Alt text |
| **Media** | Photos and files | Assets, library |
| **Trash** | Where things wait for 30 days | Bin, archive |
| **History** | Earlier versions | Revisions, versions list |
| **Owner**, **Admin**, **Editor** | What someone can do | Role, permission, user level |
| **Person**, **people** | Whoever can sign in | User |
| **Visitor** | Whoever looks at the site | User, reader |
| **Recovery kit**, **recovery code** | The way back in without email | Backup codes |
| **Setup code**, **setup password** | What setup asks for | Token, key |
| **Backup** | Everything, in one file you keep | Export, snapshot |
| **Copy** | The data, kept on the server | Snapshot |
| **Data folder** | Where the site's data is | Volume, storage, root |
| **Where Tend runs** | The computer or host | Instance, environment |
| **Update** | A newer Tend | Upgrade, migration |

Some rules:

- Say what happened, then what to do. Nothing else.
- Contractions are fine: "can't", "isn't".
- No "please", no "oops", no exclamation marks, no em dashes.
- A button says what it does: **Publish post now**, not **OK**.
- "Collection" and "webhook" are for developers' screens, when there are any.
