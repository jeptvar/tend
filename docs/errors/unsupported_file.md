# Tend can't use that kind of file

> Tend can't use that kind of file.

## What happened

Tend takes JPEG, PNG, WebP, GIF and AVIF pictures, and PDF files. It looks inside the file, so a name that says otherwise is refused as well.

## What to do

- Export it as one of those.
- If the message says the name is wrong, rename it as it suggests.
