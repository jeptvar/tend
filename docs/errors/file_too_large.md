# The file is too big

> That file is bigger than 20 MB, which is the most Tend can take.

## What happened

Tend keeps the file it's given and makes the sizes visitors get from it, all on your server. A photo over 20 MB is made smaller as it's added, so this is a PDF, a GIF, which may move, or a photo this browser couldn't read.

## What to do

- For a photo, export it as a JPEG, or at 6000 pixels wide or less.
- For a PDF, use your program's "reduce size" or "optimise" when saving it.
