# Recovery code not accepted

> That email and recovery code don't match.

## What happened

The code isn't one of this account's, or it has been used: each works once. Making a new kit also ends the codes in the old one.

## What to do

- Check the email, and the code letter by letter. The letters I, L and O are never used, so what looks like one is a digit.
- Try the next code in your kit.
- Ask the Owner for a link to choose a new password, or see [Locked out](../locked-out.md).
