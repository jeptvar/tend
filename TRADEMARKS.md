# The name

Tend's code is under [the MIT licence](LICENSE): use it, change it, sell it. The name isn't part of that. **Tend CMS** says that something comes from this project, so that people know what they're getting.

## You can

- Say that your site is made with Tend CMS, with a badge if you like.
- Say that your theme, tool, course or hosting is for Tend CMS.
- Write about it, teach it, and compare it with others.
- Sell Tend as it is, under its name, if nothing in it is changed.

## Please don't

- Call a changed version Tend, or anything that could be taken for it. Give a fork a name of its own, and say that it's based on Tend CMS.
- Use the name as the name of your company, product, domain or account, so that it looks like ours.
- Suggest that we made, checked or recommend something that we didn't.

Not sure? Open an issue and ask.
