# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and argue about the work rather than the person. Harassment isn't welcome in any form, in issues, pull requests, discussions or anywhere else that's about Tend.

To report something, use **Report a vulnerability** on this repository's **Security** tab, which only the maintainers see, and say that it's about conduct. It stays confidential. The maintainers decide what follows, from a word in private to a ban, as the Covenant describes.
