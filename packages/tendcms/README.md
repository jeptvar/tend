# Tend CMS

An easy, fast, self-hosted CMS for small websites. This package is the server, the admin and the command line.

To make a site:

```
npm create tend@latest my-site
```

It needs Node.js 24 or newer. In the site's folder, `npm start` starts it again, and `npx tendcms --help` lists what else there is.
