# create-tend

Makes a new [Tend CMS](https://tendcms.dev) site:

```
npm create tend@latest my-site
```

It needs Node.js 24 or newer. It makes the site's folder, installs Tend, starts it, and opens
your browser at the setup screen. Keep that window open: Tend stops when you close it. To start
it again later: `cd my-site`, then `npm start`.
